## 1. Architectural Overview and Program Purpose

The program [`9.1.asm`](https://github.com/b1tranger/Microprocessor_Assembly_Lab/blob/main/LabCodes/lab-9_Comparing_Numbers/9.1.asm) implements a standard two-way relational comparison between two user-entered single-digit characters ($A$ and $B$).

```
[User Input A] ---> BL
[User Input B] ---> BH
                       |
               [ CMP BL, BH ]
                       |
        +--------------+---------------+
        |                              |
     BL > BH                        BL < BH
   (JG a_is_big)                  (JL b_is_big)
        |                              |
        v                              v
   Print "A is..."                Print "B is..."
        |                              |
        +------------> JMP exit <------+
```

The execution lifecycle consists of:
1. **Prompt & Input for Variable A**: Uses `INT 21h, AH=09h` to display `a_input` ([`9.1.asm#L20-L22`](https://github.com/b1tranger/Microprocessor_Assembly_Lab/blob/main/LabCodes/lab-9_Comparing_Numbers/9.1.asm#L20-L22)), reads a single keypress via `INT 21h, AH=01h` into `AL`, and stores it into register `BL` ([`9.1.asm#L24-L26`](https://github.com/b1tranger/Microprocessor_Assembly_Lab/blob/main/LabCodes/lab-9_Comparing_Numbers/9.1.asm#L24-L26)).
2. **Carriage Return & Line Feed**: Outputs ASCII `10` (Line Feed) and `13` (Carriage Return) via `INT 21h, AH=02h` ([`9.1.asm#L28-L33`](https://github.com/b1tranger/Microprocessor_Assembly_Lab/blob/main/LabCodes/lab-9_Comparing_Numbers/9.1.asm#L28-L33)).
3. **Prompt & Input for Variable B**: Prompts for $B$, reads into `AL`, and preserves the input in register `BH` ([`9.1.asm#L35-L43`](https://github.com/b1tranger/Microprocessor_Assembly_Lab/blob/main/LabCodes/lab-9_Comparing_Numbers/9.1.asm#L35-L43)).
4. **Comparison & Flag Evaluation**: Executes `CMP BL, BH` ([`9.1.asm#L51`](https://github.com/b1tranger/Microprocessor_Assembly_Lab/blob/main/LabCodes/lab-9_Comparing_Numbers/9.1.asm#L51)) to calculate $(BL - BH)$ internally without overwriting `BL`.
5. **Conditional Branching**: Routes control to `a_is_big`, `b_is_big`, or `both_are_equal` ([`9.1.asm#L52-L54`](https://github.com/b1tranger/Microprocessor_Assembly_Lab/blob/main/LabCodes/lab-9_Comparing_Numbers/9.1.asm#L52-L54)).
6. **Output & Program Termination**: Displays the corresponding message and branches to `exit`.

## 2. Internal Mechanics of `CMP` (Subtraction Without Destination)

### ALU Operation & Status Flag Evaluation

The instruction:
```assembly
cmp bl, bh
```
performs an internal arithmetic subtraction:
$$\text{Temp} = \text{BL} - \text{BH}$$

* **Operand Preservation**: Unlike `SUB BL, BH`, which writes the difference back into destination register `BL`, `CMP` **discards the arithmetic result**. Register `BL` retains its original value untouched.
* **Flag Mutation**: `CMP` updates the 8086 status flags in the `FLAGS` register identically to `SUB`:
  - **Zero Flag (`ZF`)**: Set to `1` if $\text{BL} == \text{BH}$ (difference is zero); cleared to `0` otherwise.
  - **Sign Flag (`SF`)**: Set to `1` if the MSB (Bit 7) of $(\text{BL} - \text{BH})$ is `1` (negative result in two's complement); cleared to `0` if positive.
  - **Carry Flag (`CF`)**: Set to `1` if an unsigned borrow occurred ($\text{BL} < \text{BH}$ in unsigned representation).
  - **Overflow Flag (`OF`)**: Set to `1` if signed two's complement overflow occurred.
  - **Parity Flag (`PF`)**: Set to `1` if the low 8 bits of the difference contain an even number of set bits.
  - **Auxiliary Carry Flag (`AF`)**: Set to `1` if a borrow occurred from Bit 3 to Bit 4 (used for BCD arithmetic).

### Zero Flag (`ZF`), Sign Flag (`SF`), and Overflow Flag (`OF`)

In signed comparisons, testing whether $\text{BL} > \text{BH}$ cannot rely solely on the Sign Flag (`SF`). If a signed subtraction causes an overflow, the sign bit is inverted:
- A positive result may look negative if overflow occurs.
- A negative result may look positive if underflow occurs.

Therefore, the 8086 hardware determines signed inequality using the condition:
$$\text{Condition}(\text{Less}) \iff \text{SF} \ne \text{OF}$$
$$\text{Condition}(\text{Greater}) \iff (\text{ZF} = 0) \land (\text{SF} = \text{OF})$$

## 3. Signed vs. Unsigned Conditional Jumps (`JG`/`JL` vs. `JA`/`JB`)

### Why `9.1.asm` Uses `JG`, `JL`, `JE`

Lines 51–54 of [`9.1.asm`](https://github.com/b1tranger/Microprocessor_Assembly_Lab/blob/main/LabCodes/lab-9_Comparing_Numbers/9.1.asm#L51-L54) use:
```assembly
cmp bl, bh
jg  a_is_big          ; Jump if Greater (Signed)
jl  b_is_big          ; Jump if Less (Signed)
je  both_are_equal    ; Jump if Equal (Zero Flag set)
```

These instructions belong to the **signed integer comparison family**:
- **`JG` (Jump if Greater)**: Requires $\text{ZF} = 0$ and $\text{SF} = \text{OF}$.
- **`JL` (Jump if Less)**: Requires $\text{SF} \ne \text{OF}$.
- **`JE` (Jump if Equal)**: Requires $\text{ZF} = 1$.

### Signed vs. Unsigned Jump Flag Conditions

| Instruction | Meaning | Operand Type | Condition Flag Formula |
| :--- | :--- | :--- | :--- |
| **`JA` / `JNBE`** | Jump if Above | Unsigned | $\text{CF} = 0 \land \text{ZF} = 0$ |
| **`JB` / `JNAE`** | Jump if Below | Unsigned | $\text{CF} = 1$ |
| **`JAE` / `JNB`** | Jump if Above or Equal | Unsigned | $\text{CF} = 0$ |
| **`JBE` / `JNA`** | Jump if Below or Equal | Unsigned | $\text{CF} = 1 \lor \text{ZF} = 1$ |
| **`JG` / `JNLE`** | Jump if Greater | Signed | $\text{ZF} = 0 \land \text{SF} = \text{OF}$ |
| **`JL` / `JNGE`** | Jump if Less | Signed | $\text{SF} \ne \text{OF}$ |
| **`JGE` / `JNL`** | Jump if Greater or Equal | Signed | $\text{SF} = \text{OF}$ |
| **`JLE` / `JNG`** | Jump if Less or Equal | Signed | $\text{ZF} = 1 \lor \text{SF} \ne \text{OF}$ |
| **`JE` / `JZ`** | Jump if Equal / Zero | Both | $\text{ZF} = 1$ |
| **`JNE` / `JNZ`** | Jump if Not Equal / Not Zero | Both | $\text{ZF} = 0$ |

### ASCII Character Code Implications

When reading single characters with `INT 21h, AH=01h`:
- Digits `'0'` to `'9'` have ASCII values `30h` to `39h` (`48` to `57` decimal).
- Because `30h`–`39h` have their MSB (Bit 7) equal to `0`, they are positive in both signed ($+48..+57$) and unsigned interpretations ($48..57$).
- Therefore, for standard single-digit ASCII inputs, `JG`/`JL` and `JA`/`JB` produce identical branching behavior.
- **Architectural Best Practice**: When comparing raw characters, addresses, or byte counts, **unsigned jumps (`JA`, `JB`)** should strictly be preferred to prevent anomalies if extended ASCII characters ($\ge 80\text{h}$, where MSB = 1) are encountered.

## 4. Control Flow Architecture & Fallthrough Prevention

### The Role of `JMP exit`

In assembly language, labels do **not** partition code into isolated functions or blocks. If control reaches the end of `a_is_big` without a jump, the CPU will simply execute whatever bytes follow sequentially in memory:

```assembly
a_is_big:
    mov ah, 9
    lea dx, a
    int 21h
    jmp exit          ; CRITICAL: Skips over b_is_big and both_are_equal

b_is_big:
    mov ah, 9
    lea dx, b
    int 21h
    jmp exit          ; CRITICAL: Skips over both_are_equal

both_are_equal:
    mov ah, 9
    lea dx, c
    int 21h
    ; Falls directly into exit (no jmp needed here)
```

Without `jmp exit` on lines 61 and 68 ([`9.1.asm#L61`](https://github.com/b1tranger/Microprocessor_Assembly_Lab/blob/main/LabCodes/lab-9_Comparing_Numbers/9.1.asm#L61), [`9.1.asm#L68`](https://github.com/b1tranger/Microprocessor_Assembly_Lab/blob/main/LabCodes/lab-9_Comparing_Numbers/9.1.asm#L68)), an execution selecting `a_is_big` would print string `a`, then fall through and print string `b`, then fall through and print string `c`.

### Redundancy in Sequential Conditional Tests

In [`9.1.asm#L51-L55`](https://github.com/b1tranger/Microprocessor_Assembly_Lab/blob/main/LabCodes/lab-9_Comparing_Numbers/9.1.asm#L51-L55):
```assembly
cmp bl, bh
jg  a_is_big
jl  b_is_big
je  both_are_equal
```

Because two numbers can only be strictly greater, strictly less, or equal, testing all three with conditional jumps is redundant:
- If `bl > bh` is false, and `bl < bh` is false, `bl` **must** equal `bh`.
- Line 54 (`je both_are_equal`) can be replaced with an unconditional jump `jmp both_are_equal`, or the `both_are_equal` block can be placed directly underneath as the default fallthrough path.

## 5. Dissecting the Termination Defect in `9.1.asm`

### The Missing `INT 21h` after `mov ah, 4ch`

Examine lines 77–81 in [`9.1.asm`](https://github.com/b1tranger/Microprocessor_Assembly_Lab/blob/main/LabCodes/lab-9_Comparing_Numbers/9.1.asm#L77-L81):

```assembly
exit:
    mov ah, 4ch

main endp
end main
```

> [!CAUTION]
> **Defect**: The instruction `int 21h` is completely missing after `mov ah, 4ch`!
> 
> Simply loading register `AH` with `4Ch` **does not notify the DOS operating system**. The value `4Ch` merely sits in the high byte of `AX`.

### Hardware & OS Behavior upon Dropping into Garbage Memory

Without `int 21h`:
1. The CPU does not exit. It advances the Instruction Pointer (`IP`) past the end of the procedure.
2. In emulators like EMU8086, it may execute uninitialized memory or padded `00h` / `FFh` bytes (often decoding as `ADD [BX+SI], AL`), resulting in crashes, infinite loops, or undefined behavior.
3. In real MS-DOS, control does not return to the DOS prompt (`COMMAND.COM`), hanging the system.

**Correction**:
```assembly
exit:
    mov ah, 4ch
    int 21h           ; Triggers DOS Service 4Ch: Terminate Program cleanly
```

## 6. Step-by-Step Execution and Flag Tracing

### Case 1: $A > B$ ($A = \text{'7'}$, $B = \text{'3'}$)
- `BL` = `37h` (`55` decimal), `BH` = `33h` (`51` decimal).
- `CMP BL, BH` calculates: $37\text{h} - 33\text{h} = +4$.
- Status Flags: `ZF = 0`, `SF = 0`, `OF = 0`, `CF = 0`.
- Evaluation:
  - `jg a_is_big`: Checks `(ZF == 0) && (SF == OF)` $\rightarrow (1) \land (0 == 0) \rightarrow$ **TRUE**.
  - Control branches to `a_is_big`.
  - Displays `" A is bigger than B!$"`.
  - Executes `jmp exit`.

### Case 2: $A < B$ ($A = \text{'2'}$, $B = \text{'6'}$)
- `BL` = `32h` (`50` decimal), `BH` = `36h` (`54` decimal).
- `CMP BL, BH` calculates: $32\text{h} - 36\text{h} = -4$ (`FCh`).
- Status Flags: `ZF = 0`, `SF = 1`, `OF = 0`, `CF = 1`.
- Evaluation:
  - `jg a_is_big`: `SF == OF` ($1 == 0$) is FALSE $\rightarrow$ No jump.
  - `jl b_is_big`: Checks `SF != OF` ($1 \ne 0$) $\rightarrow$ **TRUE**.
  - Control branches to `b_is_big`.
  - Displays `" B is bigger than A!$"`.
  - Executes `jmp exit`.

### Case 3: $A = B$ ($A = \text{'5'}$, $B = \text{'5'}$)
- `BL` = `35h` (`53` decimal), `BH` = `35h` (`53` decimal).
- `CMP BL, BH` calculates: $35\text{h} - 35\text{h} = 0$.
- Status Flags: `ZF = 1`, `SF = 0`, `OF = 0`, `CF = 0`.
- Evaluation:
  - `jg a_is_big`: `ZF == 0` is FALSE $\rightarrow$ No jump.
  - `jl b_is_big`: `SF != OF` ($0 \ne 0$) is FALSE $\rightarrow$ No jump.
  - `je both_are_equal`: Checks `ZF == 1` $\rightarrow$ **TRUE**.
  - Control branches to `both_are_equal`.
  - Displays `" Both A and B is equal!$"`.
  - Falls through to `exit`.

## 7. High-Level Language (C/C++) Equivalence

```c
#include <stdio.h>

int main() {
    char a, b;

    printf("Enter the value of A: ");
    a = getchar();
    getchar(); // Consume newline

    printf("Enter the value of B: ");
    b = getchar();

    printf("\n");

    if (a > b) {
        printf(" A is bigger than B!\n");
    } else if (a < b) {
        printf(" B is bigger than A!\n");
    } else {
        printf(" Both A and B is equal!\n");
    }

    return 0; // Equivalent to mov ah, 4ch / int 21h
}
```

## 8. Corrected and Optimized Assembly Implementation

Below is the clean, bug-free, and cycle-optimized implementation resolving the missing `INT 21h` and eliminating redundant jumps:

```assembly
.model small
.stack 100h

.data
    a_input db 'Enter the value of A: $'
    b_input db 10, 13, 'Enter the value of B: $'
    msg_a   db 10, 13, ' A is bigger than B!$'
    msg_b   db 10, 13, ' B is bigger than A!$'
    msg_eq  db 10, 13, ' Both A and B is equal!$'

.code
main proc
    mov ax, @data
    mov ds, ax

    ; Prompt and read A
    mov ah, 9
    lea dx, a_input
    int 21h

    mov ah, 1
    int 21h
    mov bl, al              ; Store A in BL

    ; Prompt and read B (embedded newline in b_input saves instructions)
    mov ah, 9
    lea dx, b_input
    int 21h

    mov ah, 1
    int 21h
    mov bh, al              ; Store B in BH

    ; Compare values
    cmp bl, bh
    ja  a_is_big            ; Using unsigned JA for character codes
    jb  b_is_big            ; Using unsigned JB for character codes

    ; Default fallthrough: Both are equal
    lea dx, msg_eq
    jmp print_and_exit

a_is_big:
    lea dx, msg_a
    jmp print_and_exit

b_is_big:
    lea dx, msg_b

print_and_exit:
    mov ah, 9
    int 21h

    ; Proper program termination
    mov ah, 4ch
    int 21h

main endp
end main
```
