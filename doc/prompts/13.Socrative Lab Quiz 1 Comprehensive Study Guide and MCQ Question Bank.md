## 4. Analysis & Key Insights

1. **The Shift / Rotate Hardware Constraint**:
   On the 8086 CPU, shift and rotate instructions cannot take immediate counts $> 1$. Writing `SHL AL, 4` is invalid on 8086; only `SHL AL, 1` or `MOV CL, 4; SHL AL, CL` is valid.

2. **The `INC` / `DEC` Flag Exemption**:
   Unlike `ADD` and `SUB`, `INC` and `DEC` do **not** touch the Carry Flag (`CF`). This allows counters to be updated in multi-precision addition loops without corrupting the carry generated by `ADC`.

3. **Division Quotient/Remainder Sizing & Overflow Hazard**:
   - 8-bit division divides `AX` by an 8-bit operand, placing quotient in `AL` and remainder in `AH`.
   - If `AH` is not cleared before division, the dividend is huge, which often results in a quotient exceeding 255, immediately triggering a Divide Error Fault (`#DE` / Interrupt 0).

4. **Signed vs. Unsigned Jump Duality**:
   - Unsigned jumps (`JA`, `JB`, `JAE`, `JBE`) test `CF` and `ZF`.
   - Signed jumps (`JG`, `JL`, `JGE`, `JLE`) test `SF`, `OF`, and `ZF`.
   - Mnemonics sharing machine opcodes: `JE == JZ`, `JNE == JNZ`, `JB == JC == JNAE`, `JAE == JNC == JNB`.

5. **`LOOP` Mechanics & Flags**:
   The `LOOP` instruction decrements `CX` and branches if $CX \ne 0$. It does **not** modify any flags in the `FLAGS` register. If `CX = 0` prior to entering `LOOP`, it decrements to `0FFFFH` and iterates 65,536 times.
