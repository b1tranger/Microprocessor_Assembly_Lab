## 4. Analysis & Key Insights

1. **Nested Loop Stack Mechanics (`PUSH CX` / `POP CX`)**:
   - The 8086 CPU has only one loop register: `CX`.
   - Outer loop must push `CX` before loading the inner count.
   - Inner loop runs via `LOOP col_loop`.
   - After inner loop, outer loop count must be restored via `POP CX` before executing `LOOP row_loop`.
   - Stack alignment must be perfectly maintained across all branch paths.

2. **The 8-bit Division Hygiene Trap**:
   - `DIV reg8` divides the 16-bit register `AX`, **not** just `AL`.
   - Forgetting `XOR AH, AH` before `DIV` causes catastrophic `#DE` (Divide Error) faults because `AH` retains leftover service numbers (e.g. `01h` from `INT 21H / AH=01H`).

3. **Unsigned vs. Signed Jump Selection**:
   - For single-digit user inputs ($0 \dots 9$), values are strictly unsigned.
   - Using `JAE` (Above or Equal) for largest and `JBE` (Below or Equal) for smallest prevents unexpected behavior if comparing values $\ge 128$.

4. **Constructing the Pure Stack Approach in `labtest2A.asm`**:

   - Read $B$ and $A$ with immediate ASCII conversion (`SUB AL, '0'`).
   - Divide: `AX / BL` $\implies AL = C, AH = D$.
   - Save onto hardware stack: `PUSH AX` (stores $C$ and $D$ in a single 16-bit word) and `PUSH BX` (stores row count $B$).
   - Pop directly into `CX` (`POP CX`) to drive the pattern outer loop.
   - Use `PUSH CX` / `POP CX` for nested loop preservation.
   - Pop $AX$ back (`POP AX`) to retrieve $AL = C, AH = D$ for comparison.
   - Compare with `JAE`, format message, and emit the winning digit via `INT 21H, AH=02H`.

## 4. Analysis & Key Insights

1. **Register State After DOS Function 01h**:
   `INT 21H / AH=01H` guarantees that the high byte `AH` retains the function code `01h`. Reading `AX` instead of `AL` results in `01xxh`. Without `SUB AL, '0'`, the number is treated as $256 + 48 + \text{digit}$, producing extreme loop iteration counts.

2. **Stack Packing Efficiency**:
   Because the 8086 stack operates on 16-bit words, an 8-bit quotient (`AL`) and 8-bit remainder (`AH`) can be packed and saved in a single `PUSH AX` instruction, eliminating RAM memory traffic.
