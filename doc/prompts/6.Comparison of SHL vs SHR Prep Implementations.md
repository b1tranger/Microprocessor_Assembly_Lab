## 3. Analysis & Key Insights

1. **The Copy-Paste Bug**:
   - `shl_Semim.asm` was intended to demonstrate logical left shift (`SHL`), but contains identical code to `shr_Semim.asm` at lines 74–81, invoking `shr al, 1` instead of `shl al, 1`.
2. **Timing of ASCII Transformation**:
   - Immediate conversion (in `shr_Semim.asm`) mutates variables `quot` and `rem` from raw numerical values into ASCII character codes (`'0'` to `'9'`). If those variables need to be used in arithmetic later, they must be converted back.
   - Lazy conversion (in `shl_Semim.asm`) preserves variable contents in binary/numeric format and only converts right before printing, which adheres to standard architectural practices.
3. **Carriage Return / Line Feed Encoding**:
   - `0dh, 0ah` is standard Hexadecimal notation for `CR` (13) followed by `LF` (10).
   - `10, 13` uses decimal notation in inverted order (`LF` followed by `CR`).
