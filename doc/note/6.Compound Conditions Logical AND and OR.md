# 6. Compound Conditions: Logical AND (`&&`) & Logical OR (`||`)

This document demonstrates how high-level compound boolean expressions are compiled into assembly using short-circuit evaluation paths.

## 1. Short-Circuit Logical AND (`&&`)

### High-Level Expression
```c
if (a > 10 && b < 20) {
    action();
}
```

### Short-Circuit Execution Rule
In logical AND, **if any condition is false, the entire expression is false**. The CPU aborts evaluation immediately on the first failure.

### 8086 Assembly Implementation
```assembly
    ; Condition 1: a > 10
    cmp a, 10
    jbe skip_and         ; Inverted: If a <= 10, fail immediately!

    ; Condition 2: b < 20
    cmp b, 20
    jae skip_and         ; Inverted: If b >= 20, fail immediately!

    ; --- [BODY: Both Conditions Succeeded] ---
    call action

skip_and:
    ; Next instructions...
```

---

## 2. Short-Circuit Logical OR (`||`)

### High-Level Expression
```c
if (a == 0 || b == 0) {
    action();
}
```

### Short-Circuit Execution Rule
In logical OR, **if any condition is true, the entire expression is true**. The CPU jumps directly into the body without evaluating subsequent conditions.

### 8086 Assembly Implementation
```assembly
    ; Condition 1: a == 0
    cmp a, 0
    je do_action         ; Direct: If a == 0, take action immediately!

    ; Condition 2: b == 0
    cmp b, 0
    jne skip_or          ; If b != 0, all conditions failed -> skip!

do_action:
    ; --- [BODY: At least one condition succeeded] ---
    call action

skip_or:
    ; Next instructions...
```

## 3. Complex Mixed Expressions

For expressions like `if ((a > 5 && b < 10) || c == 0)`:
1. Break down into discrete condition checks.
2. Group the AND clauses so any failure branches to the next OR alternative.
3. If an entire branch succeeds, jump straight to the body label.
