## 1. High-Level Concept

```c
// Static array initialization
char arr[5] = {'A', 'B', 'C', 'D', 'E'};
char val = arr[2];                     // Access element 'C'

// Uninitialized array populated via user input
char input_arr[5];
for (int i = 0; i < 5; i++) {
    input_arr[i] = getchar();
}
```

## 2. Base-Index Addressing & Static Array Initialization

```assembly
.DATA
    arr DB 'A', 'B', 'C', 'D', 'E'
    val DB ?

.CODE
    MOV BX, OFFSET arr   ; BX holds base address of array
    MOV SI, 2            ; SI holds index offset i = 2
    MOV AL, [BX + SI]    ; Effective Address = DS:(BX + SI) -> fetches 'C'
    MOV val, AL
```

## 3. Uninitialized ("Empty") Arrays (`DUP(?)`)

In 8086 assembly, uninitialized buffer space is allocated in the data segment using the `DUP(?)` directive:

```assembly
.DATA
    ; 1. Initialized Array (Pre-filled values)
    arr_init    DB 'A', 'B', 'C', 'D', 'E'  ; 5 bytes: 41h, 42h, 43h, 44h, 45h
    
    ; 2. Uninitialized / "Empty" Array (Allocates space without fixed values)
    arr_empty   DB 5 DUP(?)                 ; Allocates 5 uninitialized bytes (like char arr[5];)
    
    ; 3. Zero-Initialized Array (Allocates and fills with 0)
    arr_zeros   DB 5 DUP(0)                 ; 5 bytes: 00h, 00h, 00h, 00h, 00h
    
    ; 4. Uninitialized 16-bit Word Array
    arr_words   DW 10 DUP(?)                ; Allocates 10 words (20 bytes total)
```

## 4. Taking User Input into an Array via Loop

1. **Set Loop Count**: `MOV CX, 5`
2. **Set Index Pointer**: `MOV SI, 0`
3. **Read Character**: Call DOS `INT 21H / AH=01H` (returns character in `AL`).
4. **Store into Array**: `MOV arr_empty[SI], AL`
5. **Increment Index & Repeat**: `INC SI`, followed by `LOOP`.

```assembly
    MOV SI, 0              ; Index i = 0
    MOV CX, 5              ; Loop 5 times

input_loop:
    MOV AH, 01H            ; DOS Service: Read char with echo -> AL
    INT 21H
    MOV arr_empty[SI], AL  ; Store character into arr_empty[i]
    INC SI                 ; i++
    LOOP input_loop        ; Decrement CX, jump if CX != 0
```

## 5. Complete Working Program: Array Input and Output

```assembly
.MODEL SMALL
.STACK 100H

.DATA
    PROMPT_IN   DB 'Enter 5 characters: $'
    PROMPT_OUT  DB 13, 10, 'Array contents: $'
    ARR         DB 5 DUP(?)        ; Empty array of 5 bytes

.CODE
MAIN PROC
    MOV AX, @DATA
    MOV DS, AX

    ; 1. Display Input Prompt
    MOV AH, 09H
    LEA DX, PROMPT_IN
    INT 21H

    ; 2. Read 5 Characters into ARR using Loop
    MOV SI, 0                      ; Index pointer i = 0
    MOV CX, 5                      ; Count = 5

read_loop:
    MOV AH, 01H                    ; DOS character input -> returns in AL
    INT 21H
    MOV ARR[SI], AL                ; Store AL into memory address ARR + SI
    INC SI                         ; Step by 1 byte
    LOOP read_loop                 ; CX--, if CX != 0 goto read_loop

    ; 3. Display Output Prompt
    MOV AH, 09H
    LEA DX, PROMPT_OUT
    INT 21H

    ; 4. Print Array Elements using Loop
    MOV SI, 0                      ; Reset index pointer
    MOV CX, 5                      ; Reset count to 5

print_loop:
    MOV DL, ARR[SI]                ; Load byte from array into DL
    MOV AH, 02H                    ; DOS character output service
    INT 21H
    INC SI                         ; Advance index
    LOOP print_loop                ; Repeat for all elements

    ; 5. Exit Program
    MOV AH, 4CH
    INT 21H
MAIN ENDP
END MAIN
```

## 6. Hardware Addressing Modes & Word Scaling

The 8086 hardware calculates effective addresses using the formula:
$$\text{Physical Address} = (\text{DS} \times 16) + \text{Base} (\text{BX/BP}) + \text{Index} (\text{SI/DI}) + \text{Displacement}$$

> [!TIP]
> - For **Byte Arrays (`DB`)**: Advance index using `INC SI` (step by 1 byte).
> - For **Word Arrays (`DW`)**: Advance index using `ADD SI, 2` (step by 2 bytes).
