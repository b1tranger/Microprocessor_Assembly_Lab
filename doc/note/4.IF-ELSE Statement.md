# 4. IF-ELSE Statement (`if-else`)

This document demonstrates the assembly implementation of mutual exclusion branching (`if-else`), highlighting the critical need for an unconditional jump (`JMP`) to prevent fall-through bugs.

## 1. High-Level Concept

```c
if (score >= 50) {
    result = 'P'; // Pass
} else {
    result = 'F'; // Fail
}
```

The program must execute exactly one of the two branches, never both.

---

## 2. 8086 Assembly Implementation

```assembly
    mov al, score
    cmp al, 50           ; Calculates (score - 50)
    jb  else_block       ; Unsigned Check: if score < 50 (CF=1), jump to ELSE

    ; --- [IF BLOCK: score >= 50] ---
    mov result, 'P'
    jmp end_if           ; MANDATORY: Jump past ELSE block to prevent fall-through!

else_block:
    ; --- [ELSE BLOCK: score < 50] ---
    mov result, 'F'

end_if:
    ; Subsequent program flow...
```

---

## 3. Hardware Execution Trace

```
                    [ CMP AL, 50 ]
                          |
              +-----------+-----------+
              |                       |
          (AL >= 50)              (AL < 50)
          [CF = 0]                [CF = 1]
              |                       |
              v                       v
       mov result, 'P'           (JB triggers)
              |                       |
         [JMP end_if]                 |
              |                       |
              +--------> [ end_if ] <-+
```

---

## 4. The Fall-Through Pitfall

> [!WARNING]
> Forgetting `jmp end_if` at the end of the `IF` block is one of the most common assembly bugs. 
> 
> If omitted:
> 1. `mov result, 'P'` executes.
> 2. Because assembly instructions fall through sequentially, the CPU continues right into `else_block:`.
> 3. `mov result, 'F'` executes immediately after, overwriting `'P'` with `'F'`!
