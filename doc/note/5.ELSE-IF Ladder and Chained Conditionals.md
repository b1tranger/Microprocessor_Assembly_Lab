# 5. ELSE-IF Ladder & Chained Conditionals

This document details the structure and register mechanics required to build multi-way conditional ladders (`if - else if - else`) in 8086 assembly.

## 1. High-Level Concept

```c
if (grade >= 80) {
    gpa = 'A';
} else if (grade >= 60) {
    gpa = 'B';
} else {
    gpa = 'F';
}
```

A multi-way branch evaluates conditions in strict priority order. As soon as one condition succeeds, the remaining conditions must be bypassed.

---

## 2. 8086 Assembly Implementation

```assembly
    mov al, grade

    ; --- Check Condition 1: grade >= 80 ---
    cmp al, 80
    jb check_b           ; If grade < 80, fall through to next test
    mov gpa, 'A'
    jmp end_ladder       ; Early exit: bypass all remaining ladder blocks

check_b:
    ; --- Check Condition 2: grade >= 60 ---
    cmp al, 60
    jb check_fail        ; If grade < 60, fall through to fallback
    mov gpa, 'B'
    jmp end_ladder       ; Early exit

check_fail:
    ; --- Fallback (ELSE) ---
    mov gpa, 'F'

end_ladder:
    ; Program execution resumes here
```

---

## 3. Execution Logic & Early Exit Strategy

- Each test uses an inverted jump (`JB` for unsigned values) to transfer control to the label of the *next* conditional block if the current test fails.
- If the test passes, the associated block executes, concluding with an unconditional jump (`JMP end_ladder`) that exits the entire construct.
- This ensures only one block runs, matching high-level language semantics.

---

## 4. Best Practices for Condition Ordering

1. **Order by Descending Thresholds**: When evaluating numerical ranges, test from largest threshold to smallest threshold (or vice versa) to avoid unreachable condition bugs.
2. **Use Unsigned Jumps for Percentages/Grades**: Always use `JA`, `JAE`, `JB`, `JBE` for quantities that cannot be negative.
