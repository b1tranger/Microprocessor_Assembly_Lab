## 1. While Loop (Pre-tested Loop)

Checks the condition **before** executing the loop body. If the condition is false initially, the body never executes.

```c
while (count > 0) {
    process();
    count--;
}
```

```assembly
while_start:
    cmp count, 0
    jle while_end        ; Pre-test: if count <= 0, terminate immediately

    call process
    dec count
    jmp while_start      ; Loop back to condition evaluation

while_end:
```

---

## 2. Do-While Loop (Post-tested Loop)

Executes the body **at least once**, checking the condition at the bottom.

```c
do {
    process();
    count--;
} while (count > 0);
```

```assembly
do_while_start:
    call process
    dec count

    cmp count, 0
    jg do_while_start    ; Post-test: if count > 0, loop back to start
```

## 3. For Loop (Hardware Counter Loop with `CX` & `LOOP`)

The 8086 CPU features dedicated hardware support for counter-controlled loops using the **`CX` (Count Register)** and the **`LOOP` instruction**:

```c
for (int i = 5; i > 0; i--) {
    print_star();
}
```

```assembly
    mov cx, 5            ; Set iteration count in CX

for_loop:
    call print_star
    loop for_loop        ; Decrements CX, jumps if CX != 0
```

### Register-Level Mechanics of `LOOP`:
1. Executes `CX = CX - 1`.
2. Evaluates `CX != 0`.
3. If `CX != 0`, transfers control to `for_loop`.
4. **Important**: The `LOOP` instruction **does NOT modify any flags in the FLAGS register**, allowing arithmetic flags inside the loop to remain uncorrupted!

## 4. Loop Control Statements: `break` and `continue`

```c
while (i < 100) {
    if (i == 50) break;
    if (i % 2 == 0) continue;
    process(i);
    i++;
}
```

```assembly
loop_top:
    cmp i, 100
    jae loop_exit        ; Loop termination

    ; --- BREAK: Early loop termination ---
    cmp i, 50
    je loop_exit         ; `break` jumps straight to the exit label

    ; --- CONTINUE: Skip remaining body ---
    test i, 1            ; Test lowest bit (0 = even)
    jz loop_step         ; `continue` jumps straight to the increment step

    call process

loop_step:
    inc i                ; Step/increment
    jmp loop_top

loop_exit:
```
