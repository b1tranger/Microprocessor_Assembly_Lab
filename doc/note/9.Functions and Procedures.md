## 1. High-Level Concept

```c
int square(int x) {
    return x * x;
}

int main() {
    int res = square(5);
}
```

Functions encapsulate modular blocks of logic. When called, the CPU must remember where to resume execution upon return.

---

## 2. 8086 Assembly Subroutine Structure

```assembly
.code
main proc
    mov ax, @data
    mov ds, ax

    ; Caller site:
    mov ax, 5            ; Pass argument in AX
    call square          ; 1. PUSH return address, 2. Jump to square
    mov res, ax          ; Store return value received in AX

    mov ah, 4ch
    int 21h
main endp

; Callee subroutine definition:
square proc
    mul ax               ; AX = AX * AX (DX:AX)
    ret                  ; POP return address from stack into IP
square endp
```

## 3. Stack & Register Mechanics (`CALL` / `RET`)

```
[ BEFORE CALL ]              [ AFTER CALL square ]           [ AFTER RET ]
Stack (SS:SP):               Stack (SS:SP):                  Stack (SS:SP):
+---------------+            +---------------+               +---------------+
| Earlier Data  |            | Earlier Data  |               | Earlier Data  |
+---------------+            +---------------+               +---------------+
                             | Return Addr IP| <-- SP (TOS)  
                             +---------------+
                             
SP decrements by 2           Pushes Return IP                SP increments by 2
                             IP = offset square              IP = popped Return IP
```

1. **`CALL target`**:
   - Decrements the Stack Pointer: `SP = SP - 2`.
   - Pushes the address of the next sequential instruction (`IP`) onto the stack at `[SS:SP]`.
   - Sets `IP = offset target`.
2. **`RET`**:
   - Pops the 16-bit word off the top of the stack into `IP`.
   - Increments the Stack Pointer: `SP = SP + 2`.
   - Execution resumes immediately after the original `CALL`.

## 4. Parameter Passing & Return Value Conventions

In 8086 programming, parameters are typically passed:
- **Via Registers**: Fastest method (e.g. `AX`, `BX`, `CX`, `DX`). Standard in simple programs.
- **Via the Stack**: Pushed before `CALL` and accessed using Base Pointer (`BP`) relative addressing (`[BP+4]`). Essential for reentrant or recursive routines.
- **Return Values**: Usually returned in `AL` (8-bit) or `AX` (16-bit).
