# 3. Simple IF Statement (`if (condition)`)

This document analyzes how standard high-level `if` conditional constructs are translated into 8086 assembly using the principle of **inverted branching**.

## 1. High-Level Concept

```c
if (a == b) {
    do_something();
}
// Subsequent statements...
```

In high-level languages, the body of the `if` statement executes if the condition evaluates to `true`.

---

## 2. The Inverted Branching Principle

Because assembly executes instructions sequentially from top to bottom, entering a code block when a condition is true requires **jumping over the block when the condition is false**:

```
High-Level Condition:     if (a == b) execute_body
Assembly Translation:     if (a != b) JUMP OVER execute_body
```

| High-Level Test | Assembly Comparison | Inverted Assembly Jump to Skip Body |
| :--- | :--- | :--- |
| `a == b` | `cmp a, b` | `jne skip_body` |
| `a != b` | `cmp a, b` | `je skip_body` |
| `a > b` (unsigned) | `cmp a, b` | `jbe skip_body` |
| `a >= b` (unsigned) | `cmp a, b` | `jb skip_body` |
| `a < b` (unsigned) | `cmp a, b` | `jae skip_body` |
| `a <= b` (unsigned) | `cmp a, b` | `ja skip_body` |

---

## 3. 8086 Assembly Implementation

```assembly
    mov ax, a
    cmp ax, b            ; Calculates (ax - b), updates ZF
    jne skip_if          ; Inverted check: If ZF == 0 (a != b), skip the body!

    ; --- [IF BODY] ---
    ; Executed ONLY when a == b (ZF == 1)
    call do_something

skip_if:
    ; Subsequent program flow...
```

---

## 4. Flag Mechanics Step-by-Step

1. `CMP AX, B`:
   - If $a = b$, then $a - b = 0$.
   - The ALU sets the Zero Flag: **$\mathbf{ZF = 1}$**.
2. `JNE skip_if`:
   - `JNE` branches if $\mathbf{ZF == 0}$.
   - Since $\mathbf{ZF = 1}$, the branch is **not taken**.
   - The CPU executes the very next instruction, entering the body.
3. If $a \ne b$:
   - The ALU sets **$\mathbf{ZF = 0}$**.
   - `JNE skip_if` evaluates true and sets `IP = offset skip_if`.
   - The body instructions are bypassed completely.
