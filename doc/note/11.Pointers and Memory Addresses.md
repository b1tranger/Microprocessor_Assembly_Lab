# 11. Pointers & Memory Addresses (`*ptr` and `&var`)

This document bridges pointer operations, address-of (`&`), and dereferencing (`*`) from high-level languages to 8086 register indirect addressing and the `LEA` instruction.

## 1. High-Level Concept

```c
int num = 42;
int *ptr = &num;    // Address-of: store memory address of num into ptr
int val = *ptr;     // Dereference: read value located at address in ptr
*ptr = 99;          // Indirect store: write 99 to address pointed to by ptr
```

A pointer is simply an integer variable whose value happens to be a memory address.

---

## 2. 8086 Assembly Implementation

```assembly
.data
    num dw 42
    ptr dw ?
    val dw ?

.code
main proc
    mov ax, @data
    mov ds, ax

    ; 1. Address-of (&num)
    lea bx, num          ; Load Effective Address (or: mov bx, offset num)
    mov ptr, bx          ; Store memory address in pointer variable

    ; 2. Dereference (*ptr)
    mov bx, ptr          ; Load pointer address into register BX
    mov ax, [bx]         ; Read 16-bit word at memory address [DS:BX]
    mov val, ax          ; val is now 42

    ; 3. Indirect Store (*ptr = 99)
    mov word ptr [bx], 99 ; Write 99 directly into memory address held in BX
```

---

## 3. LEA vs. OFFSET Directives

| Feature | `MOV reg, OFFSET label` | `LEA reg, label` |
| :--- | :--- | :--- |
| **Execution Time** | Assembly-time calculation | Runtime calculation by CPU ALU |
| **Instruction Size** | Typically 3 bytes | Typically 4 bytes |
| **Expressions Allowed** | Static label offsets only | Dynamic base-index expressions (`[BX+SI+5]`) |
| **Best Practice** | Simple static variables | Arrays with dynamic indexing or complex offsets |

---

## 4. Pointer Dereferencing and Explicit Sizing

When writing an immediate value through a pointer in assembly, the assembler cannot determine whether you intend to write an 8-bit byte or a 16-bit word unless you provide a size specifier:

```assembly
mov [bx], 99           ; ERROR: Ambiguous operand size! (Is 99 a byte or word?)
mov byte ptr [bx], 99  ; Valid: Writes 0x63 (1 byte)
mov word ptr [bx], 99  ; Valid: Writes 0x0063 (2 bytes)
```
